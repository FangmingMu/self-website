## Why

Mu Fangming needs a high-end, production-grade personal brand website (Portfolio) that demonstrates top-tier AI engineering, system engineering thinking, research depth, and commercial MVP capabilities. The website should replace generic static resumes with a premium dark-themed web experience inspired by industry leaders like OpenAI, Anthropic, Stripe, and Vercel.

## What Changes

- Create a Next.js (App Router) project with TypeScript.
- Implement a responsive, single-page application with a premium dark-themed design system.
- Integrate TailwindCSS, Framer Motion, Shadcn UI, and Lucide Icons.
- Build ten core sections:
  1. Hero: Title, typing animation, particles, and glow cursor.
  2. About Me: Education timeline and stats cards.
  3. Tech Universe: Interactive skills galaxy/star map with floating nodes and lasers.
  4. Featured Projects: Cards with 3D tilts and detailed drawers/modals.
  5. Work Experience: Spec-driven visual workflow.
  6. Research & Publications: Academic style metrics.
  7. AI Journey: Scroll-driven timeline.
  8. GitHub Dashboard: Mocked/Real contribution grids and language radar.
  9. Contact Me: Flowing borders and webhook-ready contact form.
  10. Footer: Built with details.

## Capabilities

### New Capabilities

- `portfolio-ui`: The comprehensive portfolio website UI showcasing Fangming Mu's personal brand, containing the Hero, About Me, Tech Universe, Featured Projects, Work Experience, Research, AI Journey, GitHub Dashboard, Contact Form, and Footer sections with premium dark-themed design and animations.

*(None)*
